01 / STORAGE

ZFS-native workflows

Snapshots, clones, quotas and image transfers work with native ZFS datasets. Keep recovery points and inspect the storage directly when you need to.

02 / REUSE

Basejails and templates

Share read-only release files between basejails. Prepare a template for an application, then clone it for another instance.

03 / CONTROL

Networking and limits

Choose shared-IP networking or VNET isolation. Apply optional RCTL resource limits when supported by the host kernel.

Start with an existing jail pool

Install. Prepare. Create.

Install the FreeBSD package or port, or download the tagged source. Packages can lag the current source release.

This example assumes an existing dedicated pool named jailpool, not the host's boot pool. Choose a jail release compatible with your host.

Installation and first jail → 
pkg install iocell

iocell activate jailpool
iocell fetch release=15.1-RELEASE
iocell create release=15.1-RELEASE tag=www01 vnet=off
iocell start www01
