iocell - A FreeBSD jail manager¶

iocell manages FreeBSD jails using ZFS, shared-IP or VNET networking, templates, clones, snapshots and optional kernel resource limits. It requires uclcmd and stores UCL configuration alongside native ZFS properties.

Start with Basic usage. A default jail is a basejail using shared read-only release files, not an independent OS copy. See Known limitations for current command restrictions and storage limitations.
